Navigasi Responsif

Membuat navigasi lebih nyaman digunakan, termasuk pada layar yang lebih kecil.

HTML + CSS + sedikit JavaScript Semua Jobsheet

Ringkasan materi

Jobsheet 3 menyempurnakan navigasi dengan tombol menu untuk membuka atau menutup navigasi. Fokusnya adalah pengalaman pengguna dan penyesuaian tata letak pada ukuran layar berbeda.

Tujuan pembelajaran

  • Menambahkan tombol menu pada navigasi.
  • Menggunakan class CSS untuk menampilkan atau menyembunyikan menu.
  • Menyesuaikan tampilan navigasi pada layar sempit.
  • Memastikan tautan tetap mudah digunakan.

File dan bagian penting

Gunakan folder Jobsheet-3/ pada project untuk memeriksa implementasi yang dibahas di halaman ini.

Catatan praktik
Perilaku tombol menu memerlukan JavaScript yang terhubung ke elemen yang benar. Periksa nama class dan selector bila tombol tidak merespons.

Langkah mencoba

  1. Buka Jobsheet-3/index.html pada browser desktop.
  2. Klik tombol menu (☰) untuk menguji navigasi.
  3. Perkecil lebar jendela browser dan pastikan menu masih bisa digunakan.

Checklist pemahaman

  • □ Saya dapat menjelaskan tujuan Jobsheet 3 dengan kata-kata sendiri.
  • □ Saya dapat menunjukkan file yang menjadi bagian utama materi ini.
  • □ Saya sudah mencoba halaman terkait dan memeriksa hasilnya di browser.
