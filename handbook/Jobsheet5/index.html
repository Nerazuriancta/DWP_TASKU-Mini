Jobsheet 5 — Dasar JavaScript

Mengenal JavaScript untuk menambahkan interaksi pada halaman web.

Daftar HandbookPortal Jobsheet

Tujuan dan Ruang Lingkup

JavaScript membuat halaman web dapat merespons tindakan pengguna. Contohnya adalah pencarian tabel, validasi input, dan konfirmasi sebelum suatu tindakan dilakukan.

Fokus belajar: memahami hubungan antara JavaScript dan elemen HTML.

Peta Berkas

  • assets/js/ — lokasi file JavaScript jika digunakan pada project.
  • Halaman HTML — menghubungkan script menggunakan elemen script.

Cara Kerja JavaScript

JavaScript dapat memilih elemen HTML, membaca nilai input, dan mengubah konten halaman. Script harus mengacu pada elemen yang benar agar dapat berjalan sesuai tujuan.

Pesan pada Console di Developer Tools dapat membantu menemukan kesalahan JavaScript.

Pengujian

  1. Uji interaksi yang tersedia pada halaman.
  2. Pastikan pencarian menampilkan hasil yang sesuai jika fitur tersebut ada.
  3. Periksa Console jika fitur tidak bekerja.
  4. Pastikan jalur file JavaScript benar.
