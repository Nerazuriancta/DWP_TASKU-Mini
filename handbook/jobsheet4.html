Perancangan Wireframe & User Flow

Merancang alur pengguna dan rancangan antarmuka sebelum menambah fitur aplikasi.

Analisis kebutuhan dan dokumentasiSemua Jobsheet

Ringkasan materi

Jobsheet 4 menyertakan dokumen docs/wireframe.md yang menjelaskan rancangan SIMPUS-Mini. Dokumen ini memetakan aktor, alur peminjaman/pengembalian, dan wireframe halaman sebagai acuan pengembangan berikutnya.

Tujuan pembelajaran

  • Membedakan aktor Tamu dan Petugas beserta aksesnya.
  • Membuat user flow untuk proses peminjaman buku.
  • Membuat user flow untuk proses pengembalian buku.
  • Menyusun wireframe sebagai gambaran awal antarmuka.

File dan bagian penting

Gunakan folder Jobsheet-4/ pada project untuk memeriksa implementasi yang dibahas di halaman ini.

Catatan praktik
Wireframe adalah rancangan, bukan fitur yang otomatis aktif di website. Jobsheet ini menjadi panduan, bukan bukti bahwa login atau transaksi peminjaman sudah berjalan.

Langkah mencoba

  1. Buka Jobsheet-4/docs/wireframe.md dengan editor teks atau VS Code.
  2. Baca bagian aktor, user flow peminjaman, dan user flow pengembalian.
  3. Bandingkan rancangan dengan halaman yang telah dibuat dan catat fitur yang belum tersedia.

Checklist pemahaman

  • □ Saya dapat menjelaskan tujuan Jobsheet 4 dengan kata-kata sendiri.
  • □ Saya dapat menunjukkan file yang menjadi bagian utama materi ini.
  • □ Saya sudah mencoba halaman terkait dan memeriksa hasilnya di browser.
