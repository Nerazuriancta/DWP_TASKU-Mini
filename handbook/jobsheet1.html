Fondasi HTML

Mengenal struktur halaman dan menyusun halaman SIMPUS-Mini menggunakan elemen HTML semantik.

HTML dasar Semua Jobsheet

Ringkasan materi

Jobsheet 1 menjadi fondasi halaman: kerangka dokumen, judul, navigasi, ringkasan, dan footer. Pada tahap ini tampilan masih sederhana karena fokusnya adalah struktur konten, bukan dekorasi.

Tujuan pembelajaran

  • Memahami struktur dokumen HTML: <!DOCTYPE html>, <html>, <head>, dan <body>.
  • Membuat heading, paragraf, tautan navigasi, dan bagian konten.
  • Menyusun halaman Beranda, Daftar Buku, Tambah Buku, Daftar Anggota, dan Tambah Anggota.
  • Menjaga struktur elemen tetap rapi dan mudah dibaca.

File dan bagian penting

Gunakan folder Jobsheet-1/ pada project untuk memeriksa implementasi yang dibahas di halaman ini.

Catatan praktik
Pada tahap ini data buku dan anggota masih berupa contoh statis di dalam HTML. Form belum menyimpan data secara permanen.

Langkah mencoba

  1. Buka Jobsheet-1/index.html di browser.
  2. Gunakan tautan navigasi untuk berpindah ke halaman buku dan anggota.
  3. Periksa bahwa heading, ringkasan, kutipan, dan footer tampil sesuai struktur HTML.

Checklist pemahaman

  • □ Saya dapat menjelaskan tujuan Jobsheet 1 dengan kata-kata sendiri.
  • □ Saya dapat menunjukkan file yang menjadi bagian utama materi ini.
  • □ Saya sudah mencoba halaman terkait dan memeriksa hasilnya di browser.
