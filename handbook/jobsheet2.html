CSS Eksternal

Memisahkan aturan tampilan dari HTML agar desain konsisten dan mudah dirawat.

HTML + CSS Semua Jobsheet

Ringkasan materi

Jobsheet 2 memperkenalkan file CSS eksternal. Struktur halaman dari Jobsheet 1 dipertahankan, sementara warna, jarak, ukuran teks, komponen ringkasan, dan tata letak diatur melalui stylesheet.

Tujuan pembelajaran

  • Membuat file assets/css/style.css.
  • Menghubungkan CSS dengan elemen <link rel="stylesheet" href="assets/css/style.css">.
  • Mengatur warna, font, margin, padding, kartu ringkasan, dan tampilan navigasi.
  • Menggunakan satu stylesheet bersama pada beberapa halaman.

File dan bagian penting

Gunakan folder Jobsheet-2/ pada project untuk memeriksa implementasi yang dibahas di halaman ini.

Catatan praktik
Jika CSS tidak terlihat, periksa kembali jalur relatif pada atribut href. Lokasi file HTML menentukan jalur yang digunakan.

Langkah mencoba

  1. Buka Jobsheet-2/index.html.
  2. Periksa apakah stylesheet berhasil dimuat dan desain konsisten.
  3. Coba ubah nilai warna atau jarak di style.css lalu refresh browser.

Checklist pemahaman

  • □ Saya dapat menjelaskan tujuan Jobsheet 2 dengan kata-kata sendiri.
  • □ Saya dapat menunjukkan file yang menjadi bagian utama materi ini.
  • □ Saya sudah mencoba halaman terkait dan memeriksa hasilnya di browser.
