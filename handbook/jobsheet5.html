Interaksi JavaScript & Validasi

Menambahkan perilaku interaktif pada antarmuka menggunakan JavaScript sisi klien.

HTML + CSS + JavaScriptSemua Jobsheet

Ringkasan materi

Jobsheet 5 menambahkan JavaScript untuk interaksi umum, seperti tombol menu, konfirmasi hapus, filter tabel, validasi form, pesan kesalahan, dan pemberitahuan setelah data form disimpan. Interaksi berjalan di browser.

Tujuan pembelajaran

  • Menginisialisasi tombol navigasi responsif.
  • Menampilkan konfirmasi sebelum tindakan hapus.
  • Memfilter baris tabel berdasarkan kata kunci.
  • Memvalidasi input form dan menampilkan pesan kesalahan.
  • Memberikan umpan balik kepada pengguna setelah pengiriman form.

File dan bagian penting

Gunakan folder Jobsheet-5/ pada project untuk memeriksa implementasi yang dibahas di halaman ini.

Catatan praktik
Validasi JavaScript membantu pengalaman pengguna, tetapi tidak menggantikan validasi server. Pada versi ini, interaksi form belum berarti data tersimpan ke database.

Langkah mencoba

  1. Buka Jobsheet-5/buku/list.html dan coba fitur filter tabel.
  2. Buka halaman tambah buku atau tambah anggota dan uji validasi form.
  3. Uji tombol hapus dan pastikan dialog konfirmasi muncul.
  4. Buka DevTools Console jika ada interaksi yang tidak berfungsi.

Checklist pemahaman

  • □ Saya dapat menjelaskan tujuan Jobsheet 5 dengan kata-kata sendiri.
  • □ Saya dapat menunjukkan file yang menjadi bagian utama materi ini.
  • □ Saya sudah mencoba halaman terkait dan memeriksa hasilnya di browser.
