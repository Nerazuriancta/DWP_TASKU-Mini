Jobsheet 6 — Data JSON dan Fetch

Mempelajari cara mengambil data JSON dan menampilkannya pada halaman web.

Daftar HandbookPortal Jobsheet

Tujuan dan Ruang Lingkup

Jobsheet 6 menggunakan JavaScript untuk mengambil data dari file JSON. Data buku dan anggota dapat dibaca lalu ditampilkan ke dalam tabel pada browser.

Fokus belajar: format JSON, fungsi fetch(), pengolahan data, dan penanganan error.

Peta Berkas

  • assets/js/buku.js — logika pemuatan data buku.
  • assets/js/anggota.js — logika pemuatan data anggota.
  • data/buku.json — data buku.
  • data/anggota.json — data anggota.
  • Halaman daftar — menampilkan tabel dan pesan status.

Mengenal JSON

JSON merupakan format teks untuk menyimpan data terstruktur. Data dapat berisi array dan objek. Nama properti serta nilai string ditulis menggunakan tanda kutip ganda.

Jika struktur JSON tidak valid, JavaScript dapat gagal membaca data tersebut.

Alur Fetch

Fungsi fetch() meminta file melalui sebuah URL. Respons diperiksa, diubah menjadi JSON, lalu datanya digunakan untuk membuat isi tabel.

Jika permintaan gagal, blok penanganan error dapat menampilkan pesan agar pengguna mengetahui bahwa data belum berhasil dimuat.

Memahami Error 404

Status 404 berarti file yang diminta tidak ditemukan pada alamat tersebut. Penyebabnya dapat berupa jalur yang tidak sesuai, file yang belum ter-deploy, atau penulisan nama file yang berbeda.

Untuk memeriksa masalah ini, buka Developer Tools, pilih tab Network, muat ulang halaman, lalu klik permintaan buku.json atau anggota.json. Periksa Request URL dan Status sebelum mengubah jalur pada kode.

Pengujian

  1. Pastikan file JSON ada pada folder yang benar.
  2. Periksa nama dan kapitalisasi file.
  3. Buka tab Network untuk melihat status permintaan JSON.
  4. Periksa Console jika ada kesalahan parsing atau JavaScript.
