JOBSHEET 01

Dasar HTML5

Membuat struktur dan isi halaman web.

1. Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membentuk struktur halaman web. HTML menentukan bagian seperti judul, paragraf, tabel, gambar, navigasi, dan formulir.

2. Struktur dasar HTML

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>SIMPUS-Mini</title>
</head>
<body>
    <h1>Sistem Informasi Perpustakaan</h1>
    <p>Selamat datang di SIMPUS-Mini.</p>
</body>
</html>
Kode Fungsi
<!DOCTYPE html> Menandai dokumen sebagai HTML5.
<html lang="id"> Elemen utama dokumen dan bahasa halaman.
<head> Berisi metadata dan informasi halaman.
<title> Menentukan judul pada tab browser.
<body> Berisi konten yang ditampilkan browser.

3. Elemen semantik HTML5

Elemen semantik menjelaskan fungsi bagian halaman agar struktur dokumen lebih mudah dipahami. 

<header>
    <h1>SIMPUS-Mini</h1>
    <nav>
        <a href="">Beranda</a>
        <a href="">Daftar Buku</a>
    </nav>
</header>

<main>
    <section>
        <h2>Daftar Buku</h2>
        <p>Informasi koleksi perpustakaan.</p>
    </section>
</main>

<footer>
    <p>SIMPUS-Mini</p>
</footer>
  • header: bagian pengantar halaman.
  • nav: bagian navigasi.
  • main: konten utama.
  • section: kelompok konten bertema tertentu.
  • footer: bagian penutup.

4. Membuat tabel daftar buku

<table>
    <thead>
        <tr>
            <th>Judul</th>
            <th>Pengarang</th>
            <th>Tahun</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Belajar HTML</td>
            <td>Andi</td>
            <td>2025</td>
        </tr>
    </tbody>
</table>

table membuat tabel, tr membuat baris, th membuat sel judul, dan td membuat sel data.

5. Membuat formulir

<form>
    <label for="judul">Judul Buku</label>
    <input type="text" id="judul" name="judul" required>

    <button type="submit">Simpan Buku</button>
</form>
  • form: membungkus input formulir.
  • label: memberikan keterangan pada input.
  • input: menerima masukan pengguna.
  • required: menandai input wajib diisi.

JOBSHEET 02

Dasar CSS3

Mengatur warna, ukuran, jarak, dan tata letak.

1. Apa itu CSS?

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan elemen HTML, seperti warna, tipografi, jarak, border, dan layout.

2. Menghubungkan file CSS

CSS eksternal ditulis dalam file terpisah, misalnya style.css, kemudian dihubungkan dari HTML. 

<link rel="stylesheet" href="style.css">

Contoh isi file CSS:

body {
    font-family: Arial, sans-serif;
    background-color: #f4f6ff;
    color: #202443;
    margin: 0;
    padding: 20px;
}

h1 {
    color: #536dfe;
}

.card {
    background-color: white;
    padding: 20px;
    border-radius: 12px;
}

3. Selector CSS

/* Selector elemen */
p {
    color: #444;
}

/* Selector class */
.card {
    padding: 16px;
}

/* Selector ID */
#judul {
    font-size: 28px;
}
Selector Contoh Fungsi
Elemen p Memilih elemen paragraf.
Class .card Memilih elemen dengan class tertentu.
ID #judul Memilih elemen dengan ID tertentu.

4. Box model

Box model terdiri dari content, padding, border, dan margin.

  • Content: isi elemen.
  • Padding: jarak isi ke border.
  • Border: garis pembatas.
  • Margin: jarak di luar border.
.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #ddd;
    margin: 16px;
    box-sizing: border-box;
}

5. Mengatur layout dengan Flexbox

.menu {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
}

Flexbox membantu mengatur posisi dan jarak elemen dalam satu dimensi. justify-content mengatur distribusi elemen, sedangkan align-items mengatur perataan pada sumbu silang.

Margin berada di luar border, sedangkan padding berada di antara content dan border.

JOBSHEET 03

Responsive Design

Membuat tampilan menyesuaikan desktop, tablet, dan ponsel.

1. Apa itu Responsive Design?

Responsive Design adalah pendekatan untuk membuat layout halaman menyesuaikan ukuran layar dan perangkat pengguna.

2. Meta viewport

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

width=device-width membuat lebar viewport mengikuti lebar perangkat. initial-scale=1.0 menentukan skala awal.

3. Media query

.container {
    width: 100%;
    padding: 16px;
}

@media (min-width: 768px) {
    .container {
        max-width: 720px;
        margin: 0 auto;
    }
}

@media (min-width: 1024px) {
    .container {
        max-width: 960px;
    }
}

Media query menerapkan CSS berdasarkan kondisi tertentu, misalnya lebar layar minimal 768 piksel.

4. Grid responsif

.card-grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 16px;
}

@media (min-width: 768px) {
    .card-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 1024px) {
    .card-grid {
        grid-template-columns: repeat(3, 1fr);
    }
}

Contoh ini menampilkan satu kolom pada layar kecil, dua kolom pada layar menengah, dan tiga kolom pada layar yang lebih lebar.

5. Gambar dan tabel responsif

img {
    max-width: 100%;
    height: auto;
}

.table-wrap {
    width: 100%;
    overflow-x: auto;
}

Gambar akan menyesuaikan lebar kontainer. Pembungkus tabel memungkinkan tabel yang lebar digeser horizontal di layar kecil.

6. Mobile-first

Mobile-first berarti desain dimulai dari layar kecil, lalu ditambahkan aturan untuk layar yang lebih besar.

Inti Jobsheet 3

Responsive Design adalah pendekatan desain. Media query, Flexbox, Grid, dan ukuran fleksibel dapat digunakan untuk menerapkannya.

JOBSHEET 03B

Bootstrap

Menggunakan framework CSS dengan class dan komponen siap pakai.

1. Apa itu Bootstrap?

Bootstrap adalah framework front-end yang menyediakan class CSS dan komponen untuk membangun antarmuka web secara lebih cepat. Bootstrap menyediakan grid, tombol, tabel, formulir, kartu, dan komponen lainnya.

2. Memasang Bootstrap melalui CDN

Tambahkan stylesheet Bootstrap di bagian head.

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
    rel="stylesheet"
>

3. Contoh halaman dengan Bootstrap

<main class="container py-4">
    <h1 class="text-primary">SIMPUS-Mini</h1>
    <p class="lead">Sistem Informasi Perpustakaan.</p>
    <button class="btn btn-primary">Tambah Buku</button>
</main>

container mengatur lebar konten, py-4 memberi padding vertikal, text-primary memberi warna teks utama, dan btn btn-primary membuat tombol bergaya utama.

4. Class Bootstrap yang sering digunakan

Class Fungsi
container Kontainer dengan lebar responsif.
row Membuat baris grid.
col-md-4 Membuat kolom pada breakpoint md ke atas.
btn btn-primary Tombol bergaya utama.
table table-striped Tabel dengan warna baris berselang-seling.
form-control Mengatur tampilan input formulir.
card Membuat komponen kartu.
mt-3 Memberi margin atas.

5. Membuat tabel daftar buku

<div class="table-responsive">
    <table class="table table-striped table-bordered">
        <thead class="table-dark">
            <tr>
                <th>Judul</th>
                <th>Pengarang</th>
                <th>Tahun</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Belajar HTML</td>
                <td>Andi</td>
                <td>2025</td>
            </tr>
        </tbody>
    </table>
</div>

table-striped membuat warna baris berselang-seling, table-bordered memberi garis pembatas, table-dark memberi tampilan gelap pada kepala tabel, dan table-responsive membantu tabel lebar pada layar kecil.

6. Membuat grid kartu

<div class="container">
    <div class="row g-3">
        <div class="col-12 col-md-4">
            <div class="card p-3">
                <h3>Data Buku</h3>
                <p>Kelola koleksi buku.</p>
            </div>
        </div>

        <div class="col-12 col-md-4">
            <div class="card p-3">
                <h3>Data Anggota</h3>
                <p>Kelola anggota perpustakaan.</p>
            </div>
        </div>

        <div class="col-12 col-md-4">
            <div class="card p-3">
                <h3>Peminjaman</h3>
                <p>Kelola transaksi peminjaman.</p>
            </div>
        </div>
    </div>
</div>

col-12 menggunakan seluruh lebar baris pada layar kecil. col-md-4 membuat kolom selebar 4 dari 12 bagian grid pada breakpoint md ke atas.

7. Membuat formulir

<form>
    <div class="mb-3">
        <label for="judul" class="form-label">Judul Buku</label>
        <input
            type="text"
            class="form-control"
            id="judul"
            name="judul"
            required
        >
    </div>

    <button type="submit" class="btn btn-primary">
        Simpan Buku
    </button>
</form>

form-label mengatur tampilan label, form-control mengatur tampilan input, dan mb-3 memberi jarak bawah.

Bootstrap bukan database

Bootstrap membantu tampilan antarmuka. Tombol dan tabel Bootstrap tidak otomatis menyimpan data. Proses tambah, ubah, hapus, dan ambil data tetap membutuhkan logika program dan sistem penyimpanan.

JOBSHEET 04

UI/UX dan Wireframe

Merancang antarmuka dan alur penggunaan sebelum coding.

1. Apa itu UI dan UX?

UI (User Interface) adalah antarmuka yang dilihat dan digunakan pengguna, seperti tombol, menu, formulir, warna, dan ikon.

UX (User Experience) berhubungan dengan pengalaman pengguna saat menggunakan aplikasi, termasuk kemudahan menemukan fitur dan menyelesaikan tugas.

Aspek Fokus Contoh SIMPUS-Mini
UI Tampilan antarmuka. Warna tombol dan bentuk tabel.
UX Kemudahan penggunaan. Pengguna mudah menemukan daftar buku.

2. Apa itu wireframe?

Wireframe adalah rancangan kasar susunan elemen halaman. Wireframe membantu menentukan posisi navigasi, judul, formulir, tabel, dan tombol sebelum membuat desain akhir.

3. Contoh wireframe daftar buku

+------------------------------------------+
| SIMPUS-Mini                  Navigasi     |
+------------------------------------------+
| Daftar Buku                              |
|                                          |
| [Cari buku................] [Cari]       |
|                                          |
| [ + Tambah Buku ]                        |
|                                          |
| Judul       Pengarang      Tahun         |
| ---------------------------------------  |
| Belajar HTML Andi           2025         |
| Dasar CSS   Budi            2024         |
+------------------------------------------+

4. Prinsip desain antarmuka

  • Konsistensi: tombol dan navigasi memiliki gaya seragam.
  • Hierarki: informasi penting mudah ditemukan.
  • Kontras: teks mudah dibaca.
  • Umpan balik: pengguna mendapat informasi setelah tindakan.
  • Aksesibilitas: antarmuka mudah digunakan oleh beragam pengguna.

5. Menghubungkan rancangan dengan HTML

<main class="container">
    <h1>Daftar Buku</h1>

    <form>
        <label for="cari">Cari buku</label>
        <input id="cari" type="search" name="cari">
        <button type="submit">Cari</button>
    </form>

    <a href="" class="btn btn-primary">Tambah Buku</a>
</main>

Wireframe menjadi acuan saat menyusun struktur HTML dan tampilan CSS. Atribut href pada contoh sengaja dikosongkan sebagai tempat mengisi alamat halaman tujuan.

JOBSHEET 05

JavaScript dan DOM

Membuat halaman merespons tindakan pengguna.

1. Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang membuat halaman web interaktif, misalnya untuk menangani klik, memeriksa formulir, mencari data, dan mengubah isi halaman.

2. Menghubungkan file JavaScript

<script src="script.js" defer></script>

Atribut src menunjuk file JavaScript eksternal. Atribut defer membuat skrip dijalankan setelah dokumen selesai diparsing.

3. Memilih elemen DOM

DOM (Document Object Model) merepresentasikan dokumen HTML sebagai struktur yang dapat diakses dan diubah dengan JavaScript. 

<h1 id="judul">Daftar Buku</h1>

<script>
    const judul = document.getElementById("judul");
    judul.textContent = "Daftar Buku SIMPUS-Mini";
</script>
  • getElementById(): memilih elemen berdasarkan ID.
  • querySelector(): memilih elemen pertama berdasarkan selector CSS.
  • textContent: membaca atau mengubah teks elemen.

4. Menangani klik tombol

<button id="tombolPesan">Tampilkan Pesan</button>
<p id="hasil"></p>

<script>
    const tombol = document.getElementById("tombolPesan");
    const hasil = document.getElementById("hasil");

    tombol.addEventListener("click", function () {
        hasil.textContent = "Selamat datang di SIMPUS-Mini!";
    });
</script>

addEventListener() mendaftarkan fungsi yang akan dijalankan ketika event tertentu terjadi, seperti klik.

5. Memeriksa formulir

<form id="formBuku">
    <label for="judulBuku">Judul buku</label>
    <input id="judulBuku" type="text" required>
    <button type="submit">Periksa</button>
</form>

<p id="pesan"></p>

<script>
    const form = document.getElementById("formBuku");
    const input = document.getElementById("judulBuku");
    const pesan = document.getElementById("pesan");

    form.addEventListener("submit", function (event) {
        event.preventDefault();

        if (input.value.trim() === "") {
            pesan.textContent = "Judul buku wajib diisi.";
            return;
        }

        pesan.textContent = "Judul buku sudah diisi.";
    });
</script>

preventDefault() mencegah tindakan bawaan formulir. trim() menghapus spasi di awal dan akhir teks. Contoh ini hanya memeriksa input di browser, belum menyimpan data.

6. Membuat pencarian sederhana

<input id="pencarian" type="search" placeholder="Cari buku...">

<ul id="daftarBuku">
    <li>Belajar HTML</li>
    <li>Dasar CSS</li>
    <li>JavaScript Pemula</li>
</ul>

<script>
    const pencarian = document.getElementById("pencarian");
    const daftar = document.querySelectorAll("#daftarBuku li");

    pencarian.addEventListener("input", function () {
        const kata = pencarian.value.toLowerCase();

        daftar.forEach(function (item) {
            item.hidden = !item.textContent.toLowerCase().includes(kata);
        });
    });
</script>

Event input berjalan ketika nilai input berubah. forEach() menjalankan fungsi untuk setiap item, sedangkan includes() memeriksa apakah teks mengandung kata pencarian.

JOBSHEET 06

Fetch API dan JSON

Mengambil data dan menampilkannya secara dinamis.

1. Apa itu JSON?

JSON (JavaScript Object Notation) adalah format teks untuk menyimpan dan bertukar data terstruktur. 

{
    "id": 1,
    "judul": "Belajar HTML",
    "pengarang": "Andi",
    "tahun": 2025,
    "tersedia": true
}

JSON menggunakan pasangan nama dan nilai. String memakai tanda kutip ganda, angka ditulis sebagai angka, dan boolean ditulis sebagai true atau false.

2. JSON array

[
    {
        "id": 1,
        "judul": "Belajar HTML"
    },
    {
        "id": 2,
        "judul": "Dasar CSS"
    }
]

Array JSON dapat menyimpan kumpulan objek. Dalam contoh ini, setiap objek merepresentasikan satu buku.

3. JSON.parse dan JSON.stringify

const teksJSON = '{"judul":"Belajar HTML","tahun":2025}';

const buku = JSON.parse(teksJSON);
console.log(buku.judul);

const teksBaru = JSON.stringify(buku);
console.log(teksBaru);

JSON.parse() mengubah teks JSON valid menjadi nilai JavaScript. JSON.stringify() mengubah nilai JavaScript menjadi teks JSON.

4. Mengambil data dengan Fetch API

fetch("data/buku.json")
    .then(function (response) {
        if (!response.ok) {
            throw new Error("Gagal mengambil data");
        }

        return response.json();
    })
    .then(function (data) {
        console.log(data);
    })
    .catch(function (error) {
        console.error("Terjadi kesalahan:", error);
    });

fetch() membuat permintaan HTTP. response.ok memeriksa status respons, response.json() membaca respons sebagai JSON, dan catch() menangani error.

5. Menampilkan data buku ke halaman

Contoh isi file data/buku.json:

[
    {
        "judul": "Belajar HTML",
        "pengarang": "Andi"
    },
    {
        "judul": "Dasar CSS",
        "pengarang": "Budi"
    }
]

HTML untuk menampilkan data:

<ul id="daftarBuku"></ul>
<p id="status"></p>

JavaScript untuk mengambil data:

const daftarBuku = document.getElementById("daftarBuku");
const status = document.getElementById("status");

fetch("data/buku.json")
    .then(function (response) {
        if (!response.ok) {
            throw new Error("Respons tidak berhasil");
        }

        return response.json();
    })
    .then(function (data) {
        daftarBuku.replaceChildren();

        data.forEach(function (buku) {
            const item = document.createElement("li");
            item.textContent = buku.judul + " — " + buku.pengarang;
            daftarBuku.appendChild(item);
        });

        status.textContent = "Data buku berhasil dimuat.";
    })
    .catch(function (error) {
        status.textContent = "Data gagal dimuat.";
        console.error(error);
    });

createElement() membuat elemen, textContent mengatur teks, dan appendChild() memasukkan elemen ke dalam daftar.

6. Alur kerja Fetch

  1. JavaScript mengirim permintaan melalui Fetch.
  2. Browser menerima respons dari sumber data.
  3. Respons diperiksa dan dibaca sebagai JSON.
  4. Data ditampilkan ke halaman.
  5. Jika gagal, aplikasi dapat menampilkan pesan error.
Catatan praktik

Fetch untuk file lokal biasanya perlu dijalankan melalui server web, bukan hanya dengan membuka file HTML langsung.

Hubungan antarmateri Jobsheet 1–6.

Materi Peran
HTML5 Membentuk struktur halaman.
CSS3 Mengatur tampilan dan tata letak.
Responsive Design Membuat layout menyesuaikan ukuran layar.
Bootstrap Menyediakan class dan komponen siap pakai.
UI/UX Membantu merancang antarmuka dan pengalaman pengguna.
JavaScript dan DOM Membuat halaman interaktif.
Fetch dan JSON Mengambil, membaca, dan menampilkan data.
Gambaran besar

HTML membangun kerangka, CSS mengatur tampilan, Responsive Design menyesuaikan layout dengan perangkat, Bootstrap menyediakan komponen antarmuka, UI/UX membantu merancang pengalaman pengguna, JavaScript menambahkan interaksi, sedangkan Fetch dan JSON mendukung pengambilan data.

08

Glosarium

Istilah penting dalam pemrograman web.

HTML

Bahasa markup untuk membentuk struktur halaman web.

CSS

Stylesheet untuk mengatur tampilan halaman.

Tag

Penanda HTML yang menunjukkan jenis elemen.

Atribut

Informasi tambahan pada elemen HTML.

Selector

Pola CSS untuk memilih elemen yang akan diberi gaya.

Box Model

Model elemen yang terdiri dari content, padding, border, dan margin.

Flexbox

Sistem layout CSS untuk mengatur elemen dalam satu dimensi.

CSS Grid

Sistem layout CSS untuk mengatur baris dan kolom.

Responsive Design

Pendekatan desain agar halaman menyesuaikan ukuran layar.

Media Query

Aturan CSS yang aktif berdasarkan kondisi perangkat atau layar.

Bootstrap

Framework front-end dengan class dan komponen siap pakai.

UI

Antarmuka yang digunakan untuk berinteraksi dengan aplikasi.

UX

Pengalaman pengguna saat menggunakan aplikasi.

Wireframe

Rancangan kasar susunan elemen pada halaman.

DOM

Representasi dokumen HTML yang dapat diakses JavaScript.

Event

Peristiwa seperti klik, input, atau submit.

API

Antarmuka untuk berkomunikasi atau bertukar data antarsistem.

Fetch API

Fasilitas JavaScript untuk membuat permintaan HTTP.

JSON

Format teks untuk menyimpan dan bertukar data terstruktur.

Asinkron

Pola kerja yang memungkinkan proses menunggu tanpa menghentikan seluruh alur program.

CDN

Jaringan distribusi konten yang menyediakan file seperti stylesheet Bootstrap.
