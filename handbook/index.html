Dokumentasi project

Handbook Jobsheet 1–6

Panduan singkat untuk memahami perkembangan project SIMPUS-Mini dari struktur HTML, CSS, navigasi, perancangan wireframe, interaksi JavaScript, hingga pemuatan data JSON.

6 Materi HTML • CSS • JavaScript
01
HTML dasar

Jobsheet 1: Fondasi HTML

Mengenal struktur halaman dan menyusun halaman SIMPUS-Mini menggunakan elemen HTML semantik.

02
HTML + CSS

Jobsheet 2: CSS Eksternal

Memisahkan aturan tampilan dari HTML agar desain konsisten dan mudah dirawat.

03
HTML + CSS + sedikit JavaScript

Jobsheet 3: Navigasi Responsif

Membuat navigasi lebih nyaman digunakan, termasuk pada layar yang lebih kecil.

04
Analisis kebutuhan dan dokumentasi

Jobsheet 4: Perancangan Wireframe & User Flow

Merancang alur pengguna dan rancangan antarmuka sebelum menambah fitur aplikasi.

05
HTML + CSS + JavaScript

Jobsheet 5: Interaksi JavaScript & Validasi

Menambahkan perilaku interaktif pada antarmuka menggunakan JavaScript sisi klien.

06
HTML + JavaScript + JSON

Jobsheet 6: Data JSON & Fetch API

Memisahkan data contoh dari HTML dan memuatnya secara dinamis menggunakan JavaScript.

Cara menggunakan handbook

  1. Pilih Jobsheet sesuai materi yang ingin dipelajari.
  2. Baca ringkasan dan tujuan pembelajaran.
  3. Buka folder Jobsheet yang disebutkan, lalu coba halaman di browser.
  4. Gunakan checklist untuk memastikan kamu sudah memahami materi.
Catatan: handbook ini merangkum isi project yang tersedia. Beberapa bagian seperti wireframe adalah dokumentasi rancangan, sedangkan penyimpanan database belum menjadi bagian dari Jobsheet 1–6.
