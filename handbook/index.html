JOBSHEET 01

Menyusun Struktur Halaman dengan HTML5

Fondasi halaman web sebelum diberi desain dan interaksi.

1. Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk menyusun struktur dan isi halaman web. HTML menentukan bagian mana yang menjadi judul, paragraf, navigasi, tabel, gambar, atau formulir.

HTML bukan bahasa pemrograman untuk mengatur alur logika seperti JavaScript. HTML lebih berfungsi sebagai kerangka yang menjelaskan struktur konten kepada browser.

2. Struktur dasar dokumen HTML

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
    <title>SIMPUS-Mini</title>
</head>
<body>
    <h1>Sistem Informasi Perpustakaan</h1>
    <p>Selamat datang di SIMPUS-Mini.</p>
</body>
</html>
KodeFungsi
<!DOCTYPE html>Memberi tahu browser bahwa dokumen menggunakan HTML5.
<html lang="id">Elemen akar dokumen; bahasa kontennya adalah Bahasa Indonesia.
<head>Berisi metadata, judul tab, dan tautan file CSS.
<meta charset="UTF-8">Mendukung berbagai karakter dan simbol.
<meta name="viewport">Membantu halaman menyesuaikan lebar layar perangkat.
<body>Berisi konten yang ditampilkan di halaman.

3. Elemen semantik HTML5

Elemen semantik menjelaskan arti atau peran suatu bagian halaman. Penggunaannya membuat struktur dokumen lebih mudah dibaca, dipelihara, dan dipahami teknologi bantu. 

<header>
    <h1>SIMPUS-Mini</h1>
    <nav>
        <a href="index.html">Beranda</a>
        <a href="buku/list.html">Daftar Buku</a>
        <a href="buku/tambah.html">Tambah Buku</a>
    </nav>
</header>

<main>
    <section>
        <h2>Selamat Datang</h2>
        <p>Kelola informasi perpustakaan.</p>
    </section>
</main>

<footer>
    <p>SIMPUS-Mini</p>
</footer>
header

Bagian pengantar halaman atau bagian tertentu.

nav

Kumpulan tautan navigasi.

main

Konten utama halaman.

section

Kelompok konten dengan tema tertentu.

article

Konten mandiri yang dapat dipahami terpisah.

footer

Bagian penutup halaman atau bagian.

4. Membuat tabel daftar buku

Tabel digunakan ketika data perlu ditampilkan dalam baris dan kolom. Pada daftar buku, satu baris biasanya mewakili satu buku, sedangkan kolom menunjukkan atribut seperti judul, pengarang, tahun terbit, dan stok. 

<div class="table-wrap">
    <table>
        <thead>
            <tr>
                <th>Judul</th>
                <th>Pengarang</th>
                <th>Tahun</th>
                <th>Stok</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Belajar HTML</td>
                <td>Andi</td>
                <td>2025</td>
                <td>5</td>
            </tr>
        </tbody>
    </table>
</div>

table membentuk tabel, thead mengelompokkan kepala tabel, tbody menampung data, tr membentuk baris, th menjadi sel judul, dan td menjadi sel data.

5. Membuat formulir tambah buku

Formulir digunakan untuk menerima masukan pengguna. Atribut name penting karena menjadi nama data ketika formulir dikirim. Atribut id membantu menghubungkan label ke input dan memudahkan pemilihan elemen. 

<form id="formBuku">
    <label for="judul">Judul Buku</label>
    <input type="text" id="judul" name="judul" required>

    <label for="pengarang">Pengarang</label>
    <input type="text" id="pengarang" name="pengarang" required>

    <label for="tahun">Tahun Terbit</label>
    <input type="number" id="tahun" name="tahun" required>

    <label for="kategori">Kategori</label>
    <select id="kategori" name="kategori">
        <option value="Teknologi">Teknologi</option>
        <option value="Novel">Novel</option>
    </select>

    <button type="submit">Simpan Buku</button>
</form>
  • label memberi keterangan pada input.
  • input menerima masukan seperti teks atau angka.
  • select menyediakan pilihan yang telah ditentukan.
  • required meminta browser memeriksa apakah input wajib sudah diisi.
  • button menyediakan tombol untuk melakukan tindakan.
Hal penting

Pada Jobsheet 1, tabel masih berisi data contoh dan formulir belum menyimpan data ke database. Fokusnya adalah membangun struktur HTML yang rapi dan konsisten.

Tanya Jawab Jobsheet 1

HTML menyusun struktur dan konten, sedangkan CSS mengatur tampilan visualnya.

Mengapa menggunakan elemen semantik?

Karena elemen semantik memberi arti yang jelas pada bagian halaman dan memudahkan pemeliharaan struktur.

Mengapa atribut name penting pada form?

Atribut name menjadi nama field ketika nilai formulir dikirim atau dibaca oleh kode.

Apakah tombol Simpan sudah menyimpan data?

Belum. HTML saja tidak menyimpan data ke database. Diperlukan proses JavaScript atau server sesuai kebutuhan aplikasi.

JOBSHEET 02

Mengimplementasikan Styling dengan CSS3

Mengubah struktur HTML menjadi antarmuka yang rapi dan konsisten.

1. Apa itu CSS?

CSS (Cascading Style Sheets) digunakan untuk mengatur warna, ukuran teks, jarak, garis tepi, posisi, dan tata letak elemen HTML. Pemisahan HTML dan CSS membuat struktur konten lebih mudah dirawat dan desain lebih mudah diubah.

2. Menghubungkan file CSS

<head>
    <link rel="stylesheet" href="assets/css/style.css">
</head>

Atribut href berisi lokasi file CSS relatif terhadap file HTML. Jika jalurnya salah, browser tidak dapat menerapkan stylesheet tersebut.

3. Selector dan properti CSS

body {
    font-family: Arial, sans-serif;
    background-color: #f4f6ff;
    color: #202443;
}

h1 {
    font-size: 28px;
    color: #536dfe;
}

.card {
    background: #ffffff;
    padding: 20px;
    border-radius: 12px;
}
  • body adalah selector elemen.
  • .card adalah selector class, ditandai titik.
  • color mengatur warna teks.
  • background-color mengatur warna latar.
  • padding mengatur ruang di dalam elemen.
  • border-radius membulatkan sudut elemen.

4. Memahami box model

Setiap elemen pada halaman dapat dipahami sebagai kotak yang terdiri dari content, padding, border, dan margin. Memahami box model membantu kita mengatur ukuran serta jarak tanpa menimbulkan layout yang tidak terduga.

Margin
Border
Padding
Content
* {
    box-sizing: border-box;
}

.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #d8def0;
    margin: 16px;
}

Dengan box-sizing: border-box, lebar elemen mencakup content, padding, dan border. Ini memudahkan perhitungan ukuran elemen pada layout.

5. Flexbox untuk navbar

Flexbox membantu menyusun elemen dalam satu dimensi, yaitu baris atau kolom. Ini cocok untuk navbar yang berisi logo di satu sisi dan tautan menu di sisi lainnya. 

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
}

.nav-menu {
    display: flex;
    align-items: center;
    gap: 20px;
}
  • display: flex mengaktifkan layout Flexbox.
  • justify-content mengatur distribusi elemen pada sumbu utama.
  • align-items mengatur posisi pada sumbu silang.
  • gap memberi jarak antar-item.

6. CSS Grid untuk kartu statistik

Grid cocok untuk layout dua dimensi yang membutuhkan baris dan kolom. Dalam SIMPUS-Mini, Grid dapat digunakan untuk menampilkan kartu Total Buku, Total Anggota, dan Total Dipinjam. 

.stats-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

.card {
    padding: 20px;
    background: white;
    border-radius: 12px;
    box-shadow: 0 4px 14px rgba(30, 45, 90, 0.08);
}

repeat(3, 1fr) membuat tiga kolom dengan porsi ruang yang sama. Pada Jobsheet 2, nilai statistik masih berupa data contoh, belum dihitung dari database.

7. Styling tabel dan formulir

table {
    width: 100%;
    border-collapse: collapse;
}

th, td {
    padding: 12px;
    border-bottom: 1px solid #e1e5f0;
    text-align: left;
}

tbody tr:nth-child(even) {
    background: #f6f7fc;
}

tbody tr:hover {
    background: #eef1ff;
}

input, select, button {
    font: inherit;
}

border-collapse menggabungkan batas antarsel. Selector :nth-child(even) memberi gaya pada baris genap, sedangkan :hover aktif saat pointer berada di atas baris.

Prinsip utama Jobsheet 2

Styling sebaiknya menggunakan class yang dapat dipakai ulang. Dengan begitu, halaman Buku dan Anggota bisa memiliki tampilan konsisten tanpa menulis aturan berbeda untuk setiap elemen.

Tanya Jawab Jobsheet 2

Apa perbedaan padding dan margin?

Padding adalah ruang di dalam batas elemen. Margin adalah ruang di luar batas elemen.

Kapan menggunakan Flexbox?

Flexbox cocok untuk menyusun elemen dalam satu arah, misalnya menu navigasi atau deretan tombol.

Kapan menggunakan Grid?

Grid cocok untuk tata letak baris dan kolom, misalnya kartu statistik atau galeri.

Mengapa menggunakan class CSS?

Class memungkinkan gaya digunakan pada banyak elemen dan membuat kode lebih konsisten.

JOBSHEET 03

Membangun Tampilan Responsif

Membuat halaman nyaman digunakan pada desktop, tablet, dan HP.

1. Apa itu responsive design?

Responsive design adalah pendekatan untuk membuat tata letak halaman menyesuaikan ukuran layar. Halaman yang terlihat rapi di laptop belum tentu nyaman digunakan di HP karena ruang tampilannya jauh lebih sempit.

2. Meta viewport

<meta name="viewport"
    content="width=device-width, initial-scale=1.0">

width=device-width membuat lebar layout mengikuti lebar perangkat. initial-scale=1.0 menentukan skala awal tampilan. Meta viewport perlu ditambahkan pada setiap halaman HTML.

3. Pendekatan mobile-first

Mobile-first berarti memulai desain dari layar kecil, lalu menambahkan penyesuaian untuk layar yang lebih besar. Pendekatan ini membantu memastikan konten dasar tetap nyaman dibaca tanpa bergantung pada lebar desktop. 

/* Aturan dasar untuk layar kecil */
.stats-grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 16px;
}

/* Tablet dan layar lebih besar */
@media (min-width: 768px) {
    .stats-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .stats-grid {
        grid-template-columns: repeat(3, 1fr);
    }
}

Media query menerapkan aturan CSS berdasarkan kondisi tertentu. Pada contoh ini, layout awal memiliki satu kolom. Mulai lebar 768 piksel menjadi dua kolom, kemudian pada 1024 piksel menjadi tiga kolom.

4. Membuat navbar menyesuaikan layar

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.nav-menu {
    display: flex;
    gap: 16px;
}

@media (max-width: 767px) {
    .nav-menu {
        flex-direction: column;
        align-items: stretch;
    }

    .navbar {
        align-items: flex-start;
    }
}

Contoh tersebut mengubah menu menjadi susunan vertikal pada layar kecil. Untuk membuat menu hamburger yang dapat dibuka dan ditutup, diperlukan kontrol tambahan; pada Jobsheet 3 hal itu dapat dibuat dengan checkbox hack, lalu disempurnakan menggunakan JavaScript di Jobsheet 5.

5. Mengatasi tabel yang terlalu lebar

Tabel sering memiliki banyak kolom. Memaksa seluruh kolom masuk ke layar HP dapat membuat tulisan terlalu kecil atau layout melebar. Salah satu solusi awal adalah membungkus tabel dengan elemen yang dapat di-scroll horizontal. 

<div class="table-wrap">
    <table>
        <!-- isi tabel -->
    </table>
</div>
.table-wrap {
    width: 100%;
    overflow-x: auto;
}

.table-wrap table {
    min-width: 600px;
    width: 100%;
}

Ketika tabel lebih lebar daripada layar, pengguna dapat menggesernya ke samping tanpa membuat seluruh halaman ikut melebar. Alternatifnya adalah mengubah setiap baris menjadi kartu pada layar kecil.

6. Menguji responsivitas

Gunakan fitur perangkat responsif di DevTools browser. Periksa apakah teks dapat dibaca, tombol mudah ditekan, menu tetap dapat digunakan, dan tidak ada elemen yang terpotong. Ukuran pengujian yang disarankan pada jobsheet adalah sekitar 480 px untuk mobile, 768 px untuk tablet, dan 1024 px atau lebih untuk desktop.

Kesalahan yang sering terjadi

Menambahkan media query saja tidak otomatis membuat halaman responsif. Lebar tetap, gambar terlalu besar, tabel panjang, atau elemen Flexbox yang tidak boleh membungkus tetap bisa menyebabkan halaman melebar. Uji hasilnya pada ukuran layar yang berbeda.

Tanya Jawab Jobsheet 3

Apa fungsi media query?

Media query menerapkan aturan CSS berdasarkan kondisi seperti lebar layar atau karakteristik perangkat.

Apa maksud mobile-first?

Desain dimulai dari layar kecil, kemudian dikembangkan untuk tablet dan desktop.

Mengapa tabel bisa di-scroll horizontal?

Karena tabel memiliki lebar minimum yang lebih besar daripada area layar. Wrapper dengan overflow-x memungkinkan pengguna menggesernya.

Apakah breakpoint harus selalu 480, 768, dan 1024 px?

Tidak. Angka tersebut bisa menjadi titik awal. Breakpoint sebaiknya dipilih berdasarkan kapan layout mulai terlihat tidak nyaman.

JOBSHEET 04

Merancang UI/UX dan Wireframe

Merencanakan pengalaman pengguna sebelum membangun fitur.

1. Memahami UI dan UX

UI (User Interface) adalah antarmuka yang dilihat dan digunakan pengguna, misalnya tombol, formulir, menu, warna, dan tabel. UX (User Experience) adalah pengalaman pengguna ketika menyelesaikan suatu tujuan menggunakan aplikasi.

Tampilan yang menarik belum tentu memiliki UX yang baik. Misalnya, tombol peminjaman yang terlihat bagus tetapi sulit ditemukan akan membuat pengguna kesulitan menyelesaikan pekerjaannya.

2. Menentukan aktor dan kebutuhan

A

Tamu

Dapat melihat katalog buku tanpa mengelola data internal.

B

Petugas

Login dan mengelola buku, anggota, peminjaman, serta pengembalian.

Aktor adalah pihak yang berinteraksi dengan sistem. Dengan menentukan aktor terlebih dahulu, kita dapat mengetahui halaman dan tindakan apa yang dibutuhkan oleh setiap pengguna.

3. Memahami user flow

User flow adalah diagram yang menggambarkan langkah-langkah pengguna untuk menyelesaikan suatu tujuan. Untuk skenario peminjaman, alur dapat dimulai ketika petugas login, memilih anggota, memilih buku, memeriksa stok, lalu menyimpan transaksi.

Diagram ini adalah gambaran konsep, bukan kode aplikasi. Keputusan seperti stok habis perlu direncanakan sebelum fitur diimplementasikan agar alur tidak hanya mencakup kondisi ideal.

4. Memahami wireframe

Wireframe adalah rancangan kerangka halaman yang menekankan susunan dan fungsi elemen. Wireframe tidak harus langsung memiliki warna akhir atau ilustrasi lengkap. Tujuannya adalah memastikan elemen penting ditempatkan secara logis.

Rancangan Jobsheet 4 mencakup halaman Login, Dashboard Petugas, Form Peminjaman, Form Pengembalian, serta Riwayat Peminjaman per anggota. Rancangan bisa dibuat menggunakan Figma, Excalidraw, atau kertas yang kemudian dipindai.

5. Konsistensi desain

Halaman baru perlu mengikuti pola navigasi, warna, tipografi, jarak, dan komponen yang sudah dirancang pada jobsheet sebelumnya. Konsistensi membantu pengguna mengenali bahwa halaman-halaman tersebut merupakan bagian dari satu aplikasi.

Catatan penting

Jobsheet 4 berfokus pada perencanaan UI/UX, user flow, dan wireframe. Wireframe menjadi acuan implementasi, bukan pengganti kode HTML, CSS, atau JavaScript.

Tanya Jawab Jobsheet 4

Apa perbedaan UI dan UX?

UI berkaitan dengan antarmuka, sedangkan UX berkaitan dengan pengalaman dan kemudahan pengguna menyelesaikan tujuan.

Apa fungsi user flow?

Menunjukkan urutan tindakan dan keputusan yang dilalui pengguna untuk menyelesaikan sebuah proses.

Mengapa wireframe dibuat sebelum implementasi?

Agar susunan halaman dan alur pengguna dapat ditinjau lebih awal sebelum banyak waktu digunakan untuk menulis kode.

Mengapa harus memikirkan kondisi stok habis?

Karena sistem harus menangani kondisi nyata, bukan hanya alur ketika semua data memenuhi harapan.

JOBSHEET 05

Manipulasi DOM dan Event JavaScript

Membuat halaman merespons tindakan pengguna.

1. Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang dapat menambahkan perilaku pada halaman web. Jika HTML membentuk struktur dan CSS mengatur tampilan, JavaScript dapat merespons klik, memeriksa input, menyaring tabel, dan mengubah elemen halaman.

Pada Jobsheet 5, interaksi masih berjalan di browser. Data belum disimpan ke server atau database.

2. Memahami DOM

DOM (Document Object Model) adalah representasi dokumen HTML yang dapat diakses dan diubah melalui JavaScript. Melalui DOM, JavaScript bisa menemukan elemen, mengubah teks, menambahkan class, atau membuat elemen baru. 

// Mengambil elemen berdasarkan ID
const judul = document.getElementById("judul");

// Mengambil elemen menggunakan selector CSS
const tombol = document.querySelector(".btn-simpan");

// Mengubah isi teks
judul.textContent = "Daftar Buku Perpustakaan";
  • getElementById() mencari elemen berdasarkan ID.
  • querySelector() mengambil elemen pertama yang cocok dengan selector CSS.
  • textContent membaca atau mengubah teks elemen.

3. Menangani event

Event adalah kejadian yang dapat ditangani oleh JavaScript, seperti klik, pengetikan, atau pengiriman form. Event listener menjalankan fungsi ketika kejadian tertentu terjadi. 

const tombol = document.querySelector("#tombolSapa");

tombol.addEventListener("click", function () {
    alert("Selamat datang di SIMPUS-Mini!");
});

addEventListener() menghubungkan sebuah elemen dengan fungsi yang akan dijalankan saat event terjadi. Pada contoh ini, fungsi berjalan saat tombol diklik.

4. Membuat validasi form

Validasi sisi klien membantu pengguna mengetahui kesalahan sebelum formulir diproses. Misalnya, judul buku tidak boleh kosong dan tahun harus berada dalam rentang yang wajar. 

const form = document.querySelector("#formBuku");
const judul = document.querySelector("#judul");
const tahun = document.querySelector("#tahun");
const pesan = document.querySelector("#pesanError");

form.addEventListener("submit", function (event) {
    const nilaiJudul = judul.value.trim();
    const nilaiTahun = Number(tahun.value);

    if (
        nilaiJudul === "" ||
        !Number.isFinite(nilaiTahun) ||
        nilaiTahun < 1000 ||
        nilaiTahun > new Date().getFullYear()
    ) {
        event.preventDefault();
        pesan.textContent = "Periksa judul dan tahun buku.";
    } else {
        pesan.textContent = "";
    }
});

value membaca nilai input, trim() menghapus spasi di awal dan akhir, Number() mengubah nilai menjadi angka, dan preventDefault() mencegah tindakan bawaan event, misalnya pengiriman form.

Elemen pesan dapat dibuat di HTML: 

<p id="pesanError" class="error" aria-live="polite"></p>

5. Memfilter daftar buku

Pencarian di sisi klien dapat menyaring baris tabel yang sudah tersedia di halaman. Saat pengguna mengetik, JavaScript membandingkan teks pencarian dengan judul setiap baris. 

const pencarian = document.querySelector("#pencarian");
const barisBuku = document.querySelectorAll("#tabelBuku tbody tr");

pencarian.addEventListener("input", function () {
    const kataKunci = pencarian.value.toLowerCase().trim();

    barisBuku.forEach(function (baris) {
        const judulBuku = baris.cells[0].textContent.toLowerCase();
        baris.style.display =
            judulBuku.includes(kataKunci) ? "" : "none";
    });
});

querySelectorAll() mengambil semua baris yang cocok. forEach() menjalankan fungsi untuk setiap baris, sedangkan includes() memeriksa apakah teks judul mengandung kata kunci.

Pastikan input pencarian memiliki ID pencarian dan tabel memiliki ID tabelBuku. Contoh di atas mengasumsikan judul buku berada di kolom pertama.

6. Konfirmasi sebelum menghapus

const tombolHapus = document.querySelectorAll(".btn-hapus");

tombolHapus.forEach(function (tombol) {
    tombol.addEventListener("click", function (event) {
        const yakin = confirm("Yakin ingin menghapus buku ini?");

        if (!yakin) {
            event.preventDefault();
        }
    });
});

confirm() menampilkan dialog konfirmasi dengan pilihan untuk melanjutkan atau membatalkan. Jika pengguna membatalkan, preventDefault() mencegah tindakan bawaan tombol atau tautan.

Dalam tahap latihan front-end, baris dapat disembunyikan atau dihapus dari tampilan. Itu belum berarti data di database ikut terhapus.

7. Membuat menu hamburger

const tombolMenu = document.querySelector("#menuToggle");
const menu = document.querySelector("#navMenu");

tombolMenu.addEventListener("click", function () {
    const terbuka = menu.classList.toggle("show");
    tombolMenu.setAttribute("aria-expanded", terbuka);
});

classList.toggle() menambahkan class jika belum ada dan menghapusnya jika sudah ada. CSS kemudian mengatur tampilan menu ketika class show aktif. Atribut aria-expanded membantu menyampaikan status menu kepada teknologi bantu.

Validasi JavaScript bukan pengaman server

Pengguna dapat menonaktifkan JavaScript atau mengirim permintaan secara manual. Karena itu, jika aplikasi nantinya menyimpan data melalui server, validasi server tetap diperlukan.

Apa itu DOM?

DOM adalah representasi dokumen HTML yang memungkinkan JavaScript menemukan dan memanipulasi elemen halaman.

Apa fungsi addEventListener?

Memasang fungsi agar dijalankan ketika event tertentu terjadi, seperti klik atau submit.

Apa perbedaan == dan ===?

JOBSHEET 06

Komunikasi Asinkron dengan Fetch dan JSON

Mengambil dan menampilkan data tanpa menulis semua data langsung di HTML.

1. Mengapa membutuhkan Fetch?

Pada halaman statis, data dapat ditulis langsung di HTML. Namun, jika jumlah data bertambah, cara tersebut membuat pemeliharaan menjadi sulit. Fetch memungkinkan JavaScript mengambil data dari sumber lain, misalnya file JSON atau endpoint API.

Jobsheet 6 menggunakan file JSON statis sebagai sumber data sementara. Pada tahap ini, data belum diambil dari database PostgreSQL.

2. Memahami JSON

JSON (JavaScript Object Notation) adalah format teks untuk merepresentasikan data. JSON sering digunakan untuk pertukaran data karena strukturnya sederhana dan dapat dibaca oleh banyak bahasa pemrograman. 

[
    {
        "judul": "Belajar HTML",
        "pengarang": "Andi",
        "tahun": 2025,
        "stok": 5
    },
    {
        "judul": "Dasar CSS",
        "pengarang": "Budi",
        "tahun": 2024,
        "stok": 3
    }
]

Contoh tersebut merupakan array yang berisi dua objek. Setiap objek memiliki properti judul, pengarang, tahun, dan stok.

  • Objek JSON menggunakan tanda kurung kurawal {}.
  • Array JSON menggunakan tanda kurung siku [].
  • Nama properti dan string menggunakan tanda kutip ganda.
  • Angka ditulis tanpa tanda kutip jika memang berupa nilai numerik.

3. Mengambil file JSON menggunakan Fetch

Misalnya file disimpan di data/buku.json. JavaScript dapat mengambilnya, mengubah respons menjadi data JSON, kemudian menggunakan data tersebut untuk membentuk tabel. 

fetch("data/buku.json")
    .then(function (response) {
        if (!response.ok) {
            throw new Error("Gagal mengambil data buku");
        }

        return response.json();
    })
    .then(function (buku) {
        console.log(buku);
    })
    .catch(function (error) {
        console.error(error);
    });

Urutannya sebagai berikut:

  1. fetch() mengirim permintaan untuk mengambil sumber data.
  2. response.ok diperiksa untuk mengetahui apakah respons HTTP berhasil.
  3. response.json() membaca isi respons dan mengubah JSON menjadi nilai JavaScript.
  4. then() menangani hasil dari proses sebelumnya.
  5. catch() menangani error yang terjadi selama rangkaian proses.

4. Menampilkan data secara dinamis

Jika tabel memiliki tbody kosong, JavaScript dapat membuat baris berdasarkan data yang berhasil diambil. 

<table id="tabelBuku">
    <thead>
        <tr>
            <th>Judul</th>
            <th>Pengarang</th>
            <th>Tahun</th>
            <th>Stok</th>
        </tr>
    </thead>
    <tbody></tbody>
</table>
const tbody = document.querySelector("#tabelBuku tbody");

fetch("data/buku.json")
    .then(function (response) {
        if (!response.ok) {
            throw new Error("Gagal memuat data");
        }

        return response.json();
    })
    .then(function (buku) {
        tbody.replaceChildren();

        buku.forEach(function (item) {
            const baris = document.createElement("tr");

            [item.judul, item.pengarang, item.tahun, item.stok]
                .forEach(function (nilai) {
                    const sel = document.createElement("td");
                    sel.textContent = nilai;
                    baris.appendChild(sel);
                });

            tbody.appendChild(baris);
        });
    })
    .catch(function () {
        tbody.innerHTML =
            '<tr><td colspan="4">Gagal memuat data.</td></tr>';
    });

createElement() membuat elemen baru, appendChild() memasukkan elemen ke elemen lain, dan replaceChildren() mengosongkan isi lama sebelum data ditampilkan kembali.

Contoh ini menggunakan textContent untuk menampilkan nilai data sebagai teks, bukan menafsirkannya sebagai HTML. Ini merupakan kebiasaan yang lebih aman ketika menampilkan data dari sumber eksternal.

5. Menampilkan indikator loading

Pengambilan data tidak selalu selesai seketika. Indikator loading memberi tahu pengguna bahwa aplikasi sedang bekerja. 

const status = document.querySelector("#statusData");
const tbody = document.querySelector("#tabelBuku tbody");

status.textContent = "Memuat data buku...";

fetch("data/buku.json")
    .then(function (response) {
        if (!response.ok) {
            throw new Error("Permintaan gagal");
        }
        return response.json();
    })
    .then(function (buku) {
        // Proses dan tampilkan data di sini.
        status.textContent = "Data berhasil dimuat.";
    })
    .catch(function () {
        status.textContent = "Gagal memuat data buku.";
    });

Elemen status di HTML dapat dibuat seperti ini: 

<p id="statusData" aria-live="polite"></p>

Untuk menguji indikator loading, jobsheet menyarankan simulasi penundaan. Dalam aplikasi nyata, tidak perlu menambahkan penundaan buatan hanya agar loading terlihat.

6. Menggunakan async/await

async/await adalah cara menulis kode asinkron dengan alur yang sering kali lebih mudah dibaca dibandingkan rangkaian then(). 

async function muatBuku() {
    try {
        const response = await fetch("data/buku.json");

        if (!response.ok) {
            throw new Error("Gagal mengambil data");
        }

        const buku = await response.json();

        console.log(buku);
    } catch (error) {
        console.error("Terjadi kesalahan:", error);
    }
}

muatBuku();

async menandai fungsi asinkron. await menunggu hasil Promise di dalam fungsi tersebut. try/catch digunakan untuk menangani error yang muncul selama proses.

7. Memahami loading dan error

Loading

Memberi tahu bahwa data sedang diambil.

Success

Data berhasil diterima dan ditampilkan.

Error

Menampilkan informasi ketika proses gagal.

Jika file salah nama, jalur salah, server tidak dapat diakses, atau respons HTTP gagal, aplikasi perlu memberi pesan yang sesuai. Perlu diingat bahwa Fetch tidak otomatis melempar error untuk semua status HTTP, seperti 404; karena itu pemeriksaan response.ok diperlukan.

Perhatikan cara menjalankan proyek

Fetch terhadap file lokal dapat gagal jika halaman dibuka langsung melalui skema file://. Jalankan proyek melalui server lokal, misalnya Live Server di VS Code, lalu pastikan jalur file JSON sesuai dengan lokasi HTML.

Tanya Jawab Jobsheet 6

Apa itu JSON?

JSON adalah format teks untuk menyimpan dan bertukar data dalam bentuk objek, array, string, angka, boolean, atau null.

Apa fungsi fetch()?

Fetch digunakan untuk mengirim permintaan dan mengambil respons dari sumber seperti file JSON atau endpoint API.

Apa perbedaan then() dan await?

Keduanya dapat digunakan untuk menangani proses asinkron. then() menggunakan callback Promise, sedangkan await membuat alur fungsi async lebih mirip urutan langkah biasa.

Mengapa perlu catch() atau try/catch?

Agar aplikasi dapat menangani kegagalan, misalnya sumber data tidak bisa diambil atau proses pengolahan data mengalami error.

Apakah data JSON sudah tersimpan di database?

Belum. Dalam Jobsheet 6, JSON adalah sumber data statis. Pengambilan data dari database melalui PHP dibahas pada materi lanjutan.
