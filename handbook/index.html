MULAI DI SINI

Pengantar Handbook

Website terdiri dari beberapa bagian yang saling berhubungan. HTML membentuk struktur halaman, CSS mengatur tampilannya, Bootstrap menyediakan komponen siap pakai, dan JavaScript membuat halaman merespons tindakan pengguna.

Pada materi berikutnya, JSON digunakan sebagai format penyimpanan data sederhana yang dapat dibaca melalui JavaScript menggunakan Fetch API.

Tujuan belajar

Memahami fungsi setiap teknologi dan mengetahui bagaimana file dalam sebuah proyek website saling berhubungan.

MATERI 01

Jobsheet 1 — Mengenal HTML

HTML adalah bahasa markup untuk menyusun struktur halaman website. Elemen HTML dapat digunakan untuk membuat judul, paragraf, tautan, tabel, gambar, dan formulir.

Contoh struktur HTML

index.html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>SIMPUS Mini</title>
</head>
<body>
    <h1>Sistem Perpustakaan Mini</h1>
    <p>Selamat datang di SIMPUS.</p>
</body>
</html>

Fungsi elemen HTML

  • <head>: menyimpan informasi halaman.
  • <body>: berisi konten halaman.
  • <h1>: membuat judul utama.
  • <p>: membuat paragraf.
  • <a>: membuat tautan.
  • <table>: menampilkan data dalam tabel.
  • <form>: mengumpulkan input pengguna.
Apa yang dipelajari?
HTML menjadi kerangka website. Tanpa CSS, halaman tetap dapat ditampilkan, tetapi tampilannya masih sederhana.
MATERI 02

Jobsheet 2 — Dasar CSS

CSS digunakan untuk mengatur tampilan elemen HTML, seperti warna, ukuran tulisan, jarak, garis tepi, dan tata letak.

Contoh kode CSS

style.css
body {
    font-family: Arial, sans-serif;
    background-color: #f7f7ff;
    color: #292943;
}

h1 {
    color: #536dfe;
}

p {
    line-height: 1.7;
}

Cara menghubungkan CSS

Di dalam head HTML
<link rel="stylesheet" href="style.css">

Atribut href menentukan lokasi file CSS. Pastikan jalur file sesuai dengan struktur folder proyek.

Hal penting

CSS mengatur tampilan, bukan menyimpan atau mengolah data aplikasi.

MATERI 03

Jobsheet 3 — Bootstrap

Bootstrap merupakan framework CSS yang menyediakan class dan komponen siap pakai. Bootstrap dapat membantu membuat tombol, kartu, navigasi, dan layout responsif.

Contoh komponen Bootstrap

HTML
<div class="container">
    <div class="card p-3">
        <h2 class="text-primary">Daftar Buku</h2>
        <button class="btn btn-primary">
            Tambah Buku
        </button>
    </div>
</div>

Fungsi beberapa class

  • container: mengatur area konten.
  • card: membuat komponen kartu.
  • p-3: memberikan padding.
  • text-primary: memberi warna teks utama Bootstrap.
  • btn btn-primary: memberikan tampilan tombol.
Perlu diingat

Bootstrap membantu tampilan komponen. Tombol untuk menyimpan data tetap membutuhkan proses pemrograman yang sesuai.

MATERI 04

Jobsheet 4 — Konsistensi Halaman

Website yang memiliki beberapa halaman sebaiknya menggunakan navigasi, warna, dan gaya komponen yang konsisten. Hal ini membuat website lebih mudah digunakan dan dikembangkan.

Contoh navigasi

HTML
<nav>
    <a href="../index.html">Beranda</a>
    <a href="list.html">Daftar Buku</a>
    <a href="../anggota/list.html">
        Daftar Anggota
    </a>
</nav>

Atribut href menentukan halaman tujuan. Tanda ../ digunakan untuk berpindah ke folder induk.

Manfaat struktur yang rapi

  • Memudahkan pengguna berpindah halaman.
  • Mengurangi pengulangan kode.
  • Memudahkan pemeliharaan proyek.
  • Menjaga konsistensi desain website.
Kenapa tautan bisa tidak berfungsi?
Periksa nama file, lokasi folder, dan jalur relatif pada atribut href. Jalur yang salah dapat menyebabkan halaman tujuan tidak ditemukan.
MATERI 05

Jobsheet 5 — JavaScript Dasar

JavaScript menambahkan interaksi pada halaman website. Salah satu contohnya adalah pencarian data pada tabel berdasarkan teks yang diketik pengguna.

Contoh filter tabel

JavaScript
const input = document.getElementById("cari");

input.addEventListener("input", function () {
    const kata = input.value.toLowerCase();

    const baris = document.querySelectorAll(
        "#tabelBuku tbody tr"
    );

    baris.forEach(function (row) {
        const isi = row.textContent.toLowerCase();

        row.style.display =
            isi.includes(kata) ? "" : "none";
    });
});

Penjelasan kode

  • getElementById(): mengambil elemen berdasarkan ID.
  • addEventListener(): menjalankan fungsi ketika event terjadi.
  • input.value: membaca teks pencarian.
  • querySelectorAll(): mengambil elemen sesuai selector.
  • forEach(): memproses setiap baris tabel.
  • style.display: mengatur tampilan baris.

Alur filter tabel

  1. Pengguna mengetik kata pencarian.
  2. JavaScript membaca kata tersebut.
  3. Program memeriksa isi setiap baris.
  4. Baris yang cocok ditampilkan dan baris lain disembunyikan.
Catatan

Filter ini hanya menyembunyikan baris pada tampilan browser. Data aslinya tidak dihapus dari sumber data.

Apa itu validasi formulir?
Validasi formulir memeriksa input pengguna sebelum diproses, misalnya memastikan kolom wajib tidak kosong atau format nilai sesuai aturan.
MATERI 06

Jobsheet 6 — JSON dan Fetch API

JSON adalah format data terstruktur. JavaScript dapat membaca data JSON melalui Fetch API, kemudian menggunakan data tersebut untuk membuat isi tabel secara dinamis.

Contoh file JSON

data/buku.json
[
    {
        "judul": "Belajar HTML",
        "penulis": "Andi",
        "tahun": 2025
    },
    {
        "judul": "Dasar JavaScript",
        "penulis": "Budi",
        "tahun": 2026
    }
]

Membaca JSON menggunakan Fetch

JavaScript
async function tampilkanBuku() {
    try {
        const response = await fetch("../data/buku.json");

        if (!response.ok) {
            throw new Error("Data gagal dimuat");
        }

        const daftarBuku = await response.json();
        const tbody = document.querySelector(
            "#tabelBuku tbody"
        );

        tbody.textContent = "";

        daftarBuku.forEach(function (buku) {
            const tr = document.createElement("tr");

            const judul = document.createElement("td");
            judul.textContent = buku.judul;

            const penulis = document.createElement("td");
            penulis.textContent = buku.penulis;

            const tahun = document.createElement("td");
            tahun.textContent = buku.tahun;

            tr.append(judul, penulis, tahun);
            tbody.appendChild(tr);
        });
    } catch (error) {
        console.error(error);
    }
}

tampilkanBuku();

Urutan proses

  1. fetch() meminta file JSON melalui URL.
  2. response.ok memeriksa keberhasilan respons HTTP.
  3. response.json() membaca respons menjadi data JavaScript.
  4. forEach() mengulang setiap data buku.
  5. createElement() membuat elemen tabel.
  6. appendChild() memasukkan baris ke tabel.

Fungsi try dan catch

try berisi proses yang dijalankan. catch menangani error, misalnya ketika file tidak ditemukan atau data gagal dibaca.

Jika fetch gagal

Periksa alamat file, lokasi JSON, dan respons pada Developer Tools. Jalankan proyek melalui web server lokal karena browser dapat membatasi permintaan file ketika HTML dibuka langsung dengan alamat file://.

Apa perbedaan HTML statis dan JSON?
Pada HTML statis, baris tabel ditulis langsung di HTML. Pada JSON, data disimpan dalam file terpisah dan dibaca menggunakan JavaScript untuk ditampilkan ke halaman.
HUBUNGAN MATERI

Bagaimana Semua Bagian Bekerja Bersama?

Setiap teknologi memiliki fungsi yang berbeda, tetapi semuanya dapat digunakan bersama dalam satu proyek website.

  1. HTML: membentuk struktur halaman.
  2. CSS: mengatur tampilan dan tata letak.
  3. Bootstrap: menyediakan komponen siap pakai.
  4. JavaScript: menangani interaksi pengguna.
  5. JSON: menyimpan data dalam format terstruktur.
  6. Fetch API: meminta data melalui URL untuk diproses JavaScript.
GLOSARIUM

Istilah Penting

HTML
Bahasa markup untuk menyusun struktur dan konten halaman website.
CSS
Bahasa stylesheet untuk mengatur tampilan halaman.
Framework
Kumpulan alat atau aturan siap pakai untuk membantu pengembangan. Bootstrap merupakan framework CSS.
JavaScript
Bahasa pemrograman yang dapat merespons event dan mengubah elemen halaman.
JSON
Format data terstruktur untuk menyimpan atau bertukar informasi.
Fetch API
Fitur JavaScript untuk meminta data dan menerima respons dari URL.
DOM
Representasi dokumen HTML yang dapat diakses dan diubah melalui JavaScript.
