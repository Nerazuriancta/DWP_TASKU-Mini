MULAI DI SINI

Pengantar Handbook

Website dibangun dari beberapa teknologi yang mempunyai tugas berbeda. HTML menyusun struktur halaman, CSS mengatur tampilannya, JavaScript menangani interaksi, PHP memproses permintaan di server, dan database menyimpan data.

Jangan langsung menghafal semua kode. Pahami terlebih dahulu tujuan kode tersebut, data yang diterima, proses yang dilakukan, dan hasil yang dihasilkan.

Tujuan belajar

Setelah mempelajari handbook ini, kamu diharapkan mampu membaca kode dasar, memahami fungsi setiap file, mengikuti alur data, dan melakukan debugging sederhana.

MATERI 01

Jobsheet 1 — Mengenal HTML

HTML adalah singkatan dari HyperText Markup Language. HTML digunakan untuk menyusun struktur dan isi halaman website, seperti judul, paragraf, gambar, tautan, tabel, dan formulir.

Contoh struktur HTML

index.html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Website Pertamaku</title>
</head>
<body>
    <h1>Selamat Datang</h1>
    <p>Ini adalah website pertamaku.</p>
</body>
</html>

Penjelasan kode

  • <!DOCTYPE html> memberi tahu browser bahwa dokumen menggunakan HTML modern.
  • <html lang="id"> menjadi elemen utama dokumen dan menunjukkan bahasa Indonesia.
  • <head> berisi informasi halaman yang tidak menjadi konten utama.
  • <meta charset="UTF-8"> membantu menampilkan huruf dan simbol dengan benar.
  • <title> menentukan judul yang muncul pada tab browser.
  • <body> berisi konten yang dilihat pengguna.
  • <h1> membuat judul utama.
  • <p> membuat paragraf.

Elemen, tag, dan atribut

Tag adalah penanda seperti <p>. Elemen adalah bagian HTML yang terbentuk dari tag dan kontennya. Atribut memberikan informasi tambahan, misalnya href pada tautan.

Contoh tautan
<a href="tentang.html">Tentang Kami</a>

Saat diklik, tautan tersebut mengarahkan pengguna ke halaman tentang.html, selama alamat file tersebut benar.

Latihan

Ubah judul menjadi nama proyekmu. Tambahkan satu paragraf yang menjelaskan tujuan website tersebut.

MATERI 02

Jobsheet 2 — Dasar CSS

CSS adalah singkatan dari Cascading Style Sheets. CSS mengatur bagaimana elemen HTML ditampilkan, misalnya warna, ukuran teks, jarak antarelemen, garis tepi, dan tata letak.

Contoh CSS

style.css
body {
    font-family: Arial, sans-serif;
    background-color: #f4f6ff;
    color: #202443;
}

h1 {
    color: #536dfe;
    font-size: 32px;
}

p {
    line-height: 1.7;
}

Cara membaca CSS

Pada CSS, selector menentukan elemen yang akan diberi gaya. Properti menentukan bagian tampilan yang diubah, sedangkan nilai menentukan pengaturan yang digunakan.

KodeFungsi
bodyMemilih elemen body.
colorMengatur warna teks.
background-colorMengatur warna latar belakang.
font-sizeMengatur ukuran teks.
line-heightMengatur jarak vertikal antarbaris.

Menghubungkan CSS dengan HTML

Di dalam elemen head
<link rel="stylesheet" href="style.css">

Atribut rel="stylesheet" menyatakan bahwa file yang dihubungkan adalah stylesheet. Atribut href menunjukkan lokasi file CSS.

Memahami responsive design

Website responsif menyesuaikan tata letak dengan ukuran layar. Contohnya, beberapa kartu yang berjajar pada laptop dapat berubah menjadi satu kolom pada HP.

Contoh media query
.kartu {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

@media (max-width: 600px) {
    .kartu {
        grid-template-columns: 1fr;
    }
}

Media query di atas mengubah susunan menjadi satu kolom ketika lebar layar maksimal 600 piksel.

Latihan

Ubah warna judul dan latar belakang. Setelah itu, kecilkan ukuran browser untuk menguji tampilan responsif.

MATERI 03

Jobsheet 3 — Bootstrap

Bootstrap adalah framework CSS yang menyediakan class siap pakai. Dengan Bootstrap, pengembang dapat membuat tombol, kartu, navigasi, formulir, dan grid tanpa menulis seluruh gaya dari awal.

Contoh komponen

HTML
<div class="container">
    <div class="card p-3">
        <h2 class="text-primary">Daftar Buku</h2>
        <p>Berikut daftar buku perpustakaan.</p>
        <button class="btn btn-primary">
            Tambah Buku
        </button>
    </div>
</div>

Fungsi class

  • container mengatur area konten dan lebarnya.
  • card membentuk komponen kartu.
  • p-3 memberi padding atau ruang di dalam elemen.
  • text-primary menggunakan warna utama Bootstrap.
  • btn memberi gaya dasar tombol.
  • btn-primary memberi gaya tombol utama.
Hal yang perlu dipahami

Bootstrap membantu mengatur tampilan. Tombol tidak otomatis menyimpan data hanya karena menggunakan class btn btn-primary. Fungsi tombol tetap perlu dibuat menggunakan HTML, JavaScript, atau proses server.

MATERI 04

Jobsheet 4 — Navigasi dan Struktur Halaman

Pada website dengan banyak halaman, navigasi membantu pengguna berpindah dari satu halaman ke halaman lain. Struktur folder yang rapi juga memudahkan pengembang menemukan file.

Contoh navigasi

HTML
<nav>
    <a href="../index.html">Beranda</a>
    <a href="list.html">Daftar Buku</a>
    <a href="../anggota/list.html">
        Daftar Anggota
    </a>
</nav>

Memahami alamat file

  • index.html menunjuk file pada lokasi relatif saat ini.
  • tentang/index.html menunjuk file dalam folder tentang.
  • ../index.html naik satu tingkat ke folder induk.

Jika tautan tidak bekerja, periksa ejaan nama file, huruf besar dan kecil, serta lokasi file tujuan.

Latihan

Buat tautan dari halaman beranda ke halaman tentang. Pastikan alamat pada atribut href sesuai dengan folder proyekmu.

MATERI 05

Jobsheet 5 — JavaScript Dasar

JavaScript adalah bahasa pemrograman yang membuat halaman website menjadi interaktif. JavaScript dapat merespons klik, membaca input, memvalidasi formulir, dan mengubah elemen HTML.

Variabel dan fungsi

JavaScript
const nama = "Nera";

function sapa(pengguna) {
    return "Halo, " + pengguna + "!";
}

console.log(sapa(nama));
  • const membuat variabel yang tidak dapat ditugaskan ulang.
  • nama adalah nama variabel.
  • function digunakan untuk mendefinisikan fungsi.
  • return mengembalikan hasil dari fungsi.
  • console.log() menampilkan informasi di console browser.

Event pada tombol

HTML
<button id="tombolSapa">Klik Saya</button>
JavaScript
const tombol = document.getElementById("tombolSapa");

tombol.addEventListener("click", function () {
    alert("Tombol berhasil diklik!");
});

getElementById() mencari elemen dengan ID tertentu. addEventListener() mendaftarkan fungsi yang dijalankan saat terjadi event, dalam contoh ini adalah klik.

Pencarian pada tabel

JavaScript
const input = document.getElementById("cari");

input.addEventListener("input", function () {
    const kata = input.value.toLowerCase();
    const baris = document.querySelectorAll(
        "#tabelBuku tbody tr"
    );

    baris.forEach(function (row) {
        const isi = row.textContent.toLowerCase();

        row.style.display =
            isi.includes(kata) ? "" : "none";
    });
});

Kode tersebut membaca kata pencarian, memeriksa isi setiap baris, kemudian menyembunyikan baris yang tidak cocok. Pastikan HTML memiliki input ber-ID cari dan tabel ber-ID tabelBuku.

Perlu diingat

Filter ini hanya mengubah tampilan tabel pada browser. Data sumber tidak dihapus dari database atau file.

MATERI 06

Jobsheet 6 — JSON dan Fetch API

JSON adalah format untuk menyimpan dan bertukar data. JavaScript dapat mengambil data dari file JSON menggunakan Fetch API, lalu menampilkan data tersebut pada halaman.

Contoh data JSON

data/buku.json
[
    {
        "judul": "Belajar HTML",
        "penulis": "Andi",
        "tahun": 2025
    },
    {
        "judul": "Dasar JavaScript",
        "penulis": "Budi",
        "tahun": 2026
    }
]

JSON menggunakan pasangan nama properti dan nilai. Nama properti serta teks ditulis dengan tanda kutip ganda. Setiap objek merepresentasikan satu data buku.

Membaca JSON menggunakan Fetch

JavaScript
async function muatBuku() {
    try {
        const response = await fetch("data/buku.json");

        if (!response.ok) {
            throw new Error("Data gagal dimuat");
        }

        const daftarBuku = await response.json();
        console.log(daftarBuku);
    } catch (error) {
        console.error("Terjadi kesalahan:", error);
    }
}

muatBuku();
  • async memungkinkan fungsi menggunakan await.
  • fetch() meminta data dari alamat tertentu.
  • await menunggu hasil operasi asynchronous.
  • response.ok memeriksa apakah status HTTP menunjukkan keberhasilan.
  • response.json() membaca respons sebagai JSON.
  • try/catch membantu menangani kesalahan.
Jika data tidak muncul

Periksa alamat file JSON, struktur folder, format JSON, dan pesan pada console browser. Coba jalankan proyek menggunakan web server lokal.

MATERI 07

Jobsheet 7 — Mengenal PHP dan Form

PHP adalah bahasa pemrograman yang biasanya dijalankan di server. PHP dapat menerima input formulir, memeriksa data, mengakses database, dan mengirimkan hasil kembali kepada browser.

Contoh formulir HTML

form.html
<form action="proses.php" method="post">
    <label for="nama">Nama:</label>
    <input type="text" id="nama" name="nama" required>
    <button type="submit">Kirim</button>
</form>

Memproses input menggunakan PHP

proses.php
<?php
$nama = $_POST['nama'] ?? '';
$nama = trim($nama);

if ($nama === '') {
    echo 'Nama wajib diisi.';
} else {
    echo 'Halo, ' .
        htmlspecialchars($nama, ENT_QUOTES, 'UTF-8');
}
?>
  • method="post" mengirim data melalui metode POST.
  • name="nama" menjadi kunci data yang diterima PHP.
  • $_POST['nama'] mengambil nilai dari input tersebut.
  • ?? '' memberi nilai kosong jika data tidak tersedia.
  • trim() menghapus spasi di awal dan akhir teks.
  • if memeriksa apakah input kosong.
  • htmlspecialchars() membantu mencegah teks pengguna ditafsirkan sebagai HTML.

Alur kerja formulir

  1. Pengguna membuka halaman formulir.
  2. Pengguna mengisi input dan menekan tombol kirim.
  3. Browser mengirim data ke file yang ditentukan oleh action.
  4. PHP membaca dan memvalidasi data.
  5. PHP mengirim respons yang ditampilkan browser.
Ingat

Validasi HTML seperti required membantu pengguna, tetapi pemeriksaan tetap harus dilakukan di PHP karena data bisa dikirim tanpa menggunakan formulir biasa.

MATERI 08

Jobsheet 8 — Koneksi Database PostgreSQL

Database digunakan untuk menyimpan data secara terstruktur. Pada aplikasi PHP, PDO dapat digunakan untuk terhubung ke PostgreSQL dan menjalankan perintah SQL.

Contoh koneksi PDO

config/koneksi.php
<?php
$host = 'localhost';
$port = '5432';
$dbname = 'tasku_mini';
$user = 'postgres';
$password = 'password_database';

$dsn = "pgsql:host=$host;port=$port;dbname=$dbname";

$pdo = new PDO($dsn, $user, $password, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION
]);
?>

Penjelasan bagian koneksi

  • host adalah alamat server database.
  • port adalah port koneksi PostgreSQL, umumnya 5432.
  • dbname adalah nama database yang digunakan.
  • user dan password adalah kredensial database.
  • pgsql: menunjukkan bahwa PDO menggunakan driver PostgreSQL.
  • new PDO() membuat koneksi ke database.
  • PDO::ERRMODE_EXCEPTION membuat kesalahan koneksi atau query lebih mudah ditangani melalui exception.

Contoh query SQL

SQL
SELECT * FROM mata_kuliah;

INSERT INTO mata_kuliah (nama_matkul, dosen, kelas)
VALUES ('Basis Data', 'Bu Rina', 'TI-2D');
  • SELECT membaca data.
  • INSERT menambahkan data.
  • UPDATE mengubah data.
  • DELETE menghapus data.
Jika koneksi gagal

Periksa apakah PostgreSQL aktif, nama database benar, port sesuai, username dan password benar, serta ekstensi pdo_pgsql tersedia pada PHP.

Ganti nilai contoh password dengan kredensial lokalmu. Jangan menaruh password asli di repositori publik.

MATERI 09

Jobsheet 9 — CRUD

CRUD merupakan singkatan dari Create, Read, Update, dan Delete. Keempat operasi ini adalah dasar pengelolaan data pada aplikasi.

OperasiFungsiContoh
CreateMembuat data baru.Menambahkan tugas.
ReadMembaca data.Melihat daftar tugas.
UpdateMengubah data.Mengubah status tugas.
DeleteMenghapus data.Menghapus tugas.

Read — membaca data

PHP
<?php
$stmt = $pdo->query(
    'SELECT id_matkul, nama_matkul
     FROM mata_kuliah
     ORDER BY nama_matkul'
);

$matkul = $stmt->fetchAll(PDO::FETCH_ASSOC);
?>

query() mengirim perintah SQL. fetchAll() mengambil seluruh baris hasil, sedangkan PDO::FETCH_ASSOC membuat data dapat diakses melalui nama kolom, misalnya $baris['nama_matkul'].

Create — menambah data dengan prepared statement

PHP
<?php
$sql = 'INSERT INTO mata_kuliah
        (nama_matkul, dosen, kelas)
        VALUES (:nama, :dosen, :kelas)';

$stmt = $pdo->prepare($sql);

$stmt->execute([
    ':nama' => $nama,
    ':dosen' => $dosen,
    ':kelas' => $kelas
]);
?>

prepare() menyiapkan query dengan parameter. execute() mengirimkan nilai parameter dan menjalankan query tersebut. Cara ini membantu melindungi query dari SQL injection.

Update dan Delete

Contoh SQL
UPDATE mata_kuliah
SET nama_matkul = :nama
WHERE id_matkul = :id;

DELETE FROM mata_kuliah
WHERE id_matkul = :id;
Hati-hati dengan WHERE

Kondisi WHERE menentukan baris yang diubah atau dihapus. Tanpa kondisi yang tepat, query dapat memengaruhi seluruh baris pada tabel.

MATERI 10

Jobsheet 10 — Register, Login, dan Session

Autentikasi adalah proses memeriksa identitas pengguna. Pada aplikasi web, pengguna biasanya memasukkan username atau email dan password. Jika berhasil, aplikasi menyimpan status login menggunakan session.

Alur register dan login

  1. Pengguna mengisi formulir pendaftaran.
  2. Server memvalidasi data yang dikirim.
  3. Password disimpan dalam bentuk hash, bukan teks asli.
  4. Saat login, server mencari akun berdasarkan username atau email.
  5. Server memeriksa password menggunakan password_verify().
  6. Jika benar, server menyimpan identitas pengguna ke session.
  7. Halaman yang dilindungi memeriksa session sebelum ditampilkan.

Membuat password hash

PHP
$hash = password_hash($password, PASSWORD_DEFAULT);

// Simpan $hash ke database,
// bukan password asli pengguna.

password_hash() membuat representasi hash password. Saat login, password_verify() dapat digunakan untuk memeriksa password yang dimasukkan dengan hash yang tersimpan.

Memeriksa session

Contoh pemeriksaan login
<?php
session_start();

if (!isset($_SESSION['user_id'])) {
    header('Location: ../auth/login.php');
    exit;
}
?>
  • session_start() membuka atau melanjutkan session.
  • $_SESSION['user_id'] menyimpan identitas pengguna yang login.
  • isset() memeriksa apakah identitas tersebut tersedia.
  • header() mengarahkan browser ke halaman login.
  • exit menghentikan proses setelah redirect.
Hal penting

Letakkan pemeriksaan session sebelum HTML dikirim ke browser. Pastikan juga halaman yang dilindungi melakukan pemeriksaan sendiri, bukan hanya menyembunyikan tombol atau tautan.

MATERI 11

Jobsheet 11 — Keamanan Web

Keamanan web bertujuan mencegah input berbahaya, akses tanpa izin, dan permintaan yang tidak sah. Keamanan bukan hanya satu fitur, melainkan gabungan beberapa langkah perlindungan.

1. SQL Injection

SQL injection terjadi ketika input pengguna dimasukkan ke query sebagai bagian dari perintah SQL. Gunakan prepared statement agar nilai input diperlakukan sebagai parameter.

Contoh prepared statement
$stmt = $pdo->prepare(
    'SELECT id, password_hash
     FROM users
     WHERE username = :username'
);

$stmt->execute([
    ':username' => $username
]);

$user = $stmt->fetch(PDO::FETCH_ASSOC);

2. XSS dan escaping output

XSS dapat terjadi ketika data yang dimasukkan pengguna ditampilkan sebagai HTML atau skrip tanpa pengamanan yang sesuai.

PHP
echo htmlspecialchars(
    $namaTugas,
    ENT_QUOTES,
    'UTF-8'
);

Untuk teks biasa yang ditampilkan ke HTML, fungsi tersebut membantu mengubah karakter khusus menjadi representasi yang aman.

3. Session dan akses halaman

Halaman yang membutuhkan login harus memeriksa session pada sisi server. Pengguna yang belum login tidak boleh dapat mengaksesnya hanya dengan mengetik URL secara langsung.

4. CSRF

CSRF adalah serangan yang membuat browser pengguna mengirim permintaan tanpa disadari. Formulir yang mengubah data perlu perlindungan token CSRF yang dibuat dan diverifikasi di server.

5. Pengujian keamanan

  • Uji login dengan username dan password yang benar.
  • Uji login dengan data salah.
  • Coba input ' OR '1'='1; input tersebut tidak boleh melewati autentikasi.
  • Coba membuka halaman terlindungi sebelum login.
  • Periksa bahwa data pengguna yang ditampilkan di-escape.
  • Periksa perlindungan CSRF pada proses perubahan data.
Ingat

Prepared statement, validasi input, escaping output, pemeriksaan session, dan perlindungan CSRF menangani risiko yang berbeda. Satu langkah tidak menggantikan langkah lainnya.

MATERI 12

Jobsheet 12 — Integrasi API dan JSON

API menjadi penghubung antarkomponen aplikasi. JavaScript dapat mengirim permintaan ke API, PHP memproses permintaan tersebut, database menyediakan atau menyimpan data, lalu server mengirim respons kepada browser.

Alur permintaan

  1. Pengguna membuka halaman atau menekan tombol.
  2. JavaScript mengirim permintaan melalui fetch().
  3. PHP API memvalidasi permintaan dan data yang diterima.
  4. PHP menjalankan query database jika diperlukan.
  5. API mengirim respons, misalnya dalam format JSON.
  6. JavaScript membaca respons dan memperbarui tampilan.

Contoh mengambil data dari API

JavaScript
async function muatTugas() {
    try {
        const response = await fetch("../api/index.php");

        if (!response.ok) {
            throw new Error(
                "Permintaan gagal: " + response.status
            );
        }

        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error("Gagal memuat tugas:", error);
    }
}

muatTugas();
  • fetch() mengirim permintaan ke URL API.
  • response.ok memeriksa status keberhasilan HTTP.
  • response.json() membaca respons sebagai JSON.
  • console.log() membantu melihat data saat pengembangan.
  • catch menangani kesalahan yang terjadi.

Contoh respons JSON

Respons API
{
    "success": true,
    "message": "Data berhasil dibaca",
    "data": [
        {
            "id_tugas": 1,
            "nama_tugas": "Jobsheet 4",
            "status": "Selesai"
        }
    ]
}

JSON adalah format pertukaran data, bukan database. Pastikan respons API benar-benar berupa JSON dan alamat pada fetch() sesuai dengan struktur folder aplikasi.

Jika API gagal

Periksa URL, status HTTP, format JSON, pesan error PHP, koneksi database, dan tab Network pada Developer Tools.

RANGKUMAN

Bagaimana Semua Bagian Bekerja Bersama?

Contohnya, ketika pengguna menambahkan tugas, data melewati beberapa bagian aplikasi.

  1. HTML: menampilkan formulir input tugas.
  2. CSS: mengatur tampilan formulir.
  3. JavaScript: menangani interaksi jika digunakan.
  4. PHP: menerima dan memvalidasi data di server.
  5. PDO: mengirim query ke database.
  6. PostgreSQL: menyimpan data tugas.
  7. Respons: server mengirim hasil kembali ke browser.

Latihan mandiri

Pilih satu fitur dari proyekmu. Temukan file formulir, file proses, file koneksi database, query SQL, dan halaman yang menampilkan hasil. Tuliskan fungsi masing-masing file.

Catatan belajar
