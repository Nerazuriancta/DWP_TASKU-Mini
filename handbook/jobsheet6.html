Data JSON & Fetch API

Memisahkan data contoh dari HTML dan memuatnya secara dinamis menggunakan JavaScript.

HTML + JavaScript + JSON Semua Jobsheet

Ringkasan materi

Jobsheet 6 menggunakan file JSON sebagai sumber data buku dan anggota. File JavaScript mengambil data tersebut lalu mengisi tabel di halaman. Ini memperkenalkan pola pemisahan data dari tampilan.

Tujuan pembelajaran

  • Mengenali format JSON sebagai data terstruktur.
  • Membaca data dari data/buku.json dan data/anggota.json.
  • Menggunakan fetch() untuk mengambil file JSON.
  • Mengubah data menjadi baris tabel pada halaman.
  • Memahami bahwa permintaan fetch umumnya membutuhkan web server lokal.

File dan bagian penting

Gunakan folder Jobsheet-6/ pada project untuk memeriksa implementasi yang dibahas di halaman ini.

Catatan praktik
Jalankan melalui server lokal, bukan hanya membuka file HTML dengan file://. Fetch dapat diblokir atau berperilaku berbeda saat halaman dibuka langsung dari sistem berkas.

Langkah mencoba

  1. Jalankan folder melalui server lokal, misalnya Laragon atau ekstensi Live Server.
  2. Buka Jobsheet-6/buku/list.html dan Jobsheet-6/anggota/list.html melalui server.
  3. Pastikan baris tabel terisi dari file JSON.
  4. Jika gagal, periksa tab Network dan Console serta jalur file JSON.

Checklist pemahaman

  • □ Saya dapat menjelaskan tujuan Jobsheet 6 dengan kata-kata sendiri.
  • □ Saya dapat menunjukkan file yang menjadi bagian utama materi ini.
  • □ Saya sudah mencoba halaman terkait dan memeriksa hasilnya di browser.
