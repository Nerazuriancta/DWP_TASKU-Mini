Jobsheet 4 — Navigasi dan Tautan

Mempelajari perpindahan antarhalaman dan penggunaan alamat tautan.

Daftar HandbookPortal Jobsheet

Tujuan dan Ruang Lingkup

Navigasi membantu pengguna berpindah dari halaman utama ke halaman daftar buku, anggota, maupun formulir. Tautan yang benar membuat aplikasi lebih mudah digunakan.

Peta Berkas

  • index.html — beranda.
  • buku/list.html — daftar buku.
  • anggota/list.html — daftar anggota.

Tautan Relatif

Alamat relatif dihitung berdasarkan lokasi file HTML yang sedang dibuka. Misalnya, ../index.html berarti naik satu tingkat folder lalu membuka file index.html.

Karena itu, tautan dari halaman utama dan tautan dari subfolder mungkin membutuhkan jalur yang berbeda.

Pengujian

  1. Klik setiap menu navigasi.
  2. Uji tautan dari halaman utama dan subfolder.
  3. Pastikan tidak ada halaman yang gagal dibuka.
  4. Periksa penulisan nama file dan folder saat deployment.
